# PRIZ — магазин спортивной одежды

Сайт без сборки: HTML, CSS и JavaScript. Откройте `index.html` в браузере или загрузите папку на любой хостинг (Netlify, Vercel, GitHub Pages).

## Структура

- `index.html` — каркас страницы, шапка, подвал
- `css/style.css` — весь дизайн (цвета и шрифты в переменных `:root`)
- `js/data.js` — каталог товаров и иллюстрации
- `js/app.js` — страницы, корзина, избранное, оформление заказа
- `js/config.js` — настройки: валюта, порог бесплатной доставки, подключение Supabase
- `supabase/schema.sql` — таблицы заказов

## Как заменить рисунки на фото

В `js/data.js` добавьте товару поле `images: ["img/apex-1.jpg"]`. Фото покажется вместо рисунка.

## Как подключить заказы к Supabase

1. Создайте проект Supabase (на бесплатном тарифе доступно 2 активных проекта).
2. SQL Editor → вставьте `supabase/schema.sql` → Run.
3. Settings → API: скопируйте Project URL и publishable (anon) ключ в `js/config.js`.

Пока ключи пусты, заказы сохраняются только в браузере (демо-режим). Сайт может только создавать заказы, читать их можно в Table Editor Supabase.
